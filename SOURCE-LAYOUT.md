# AnimationLab tools repository

This private repository contains the AnimationLab production pipeline, directing skills, Windows launchers, templates, renderer demos, and benchmark tools. The original README describes the Windows lab layout. The authored film projects live in the local AnimationLab folder.

Git submodules pin the upstream tools at their original lab paths. After cloning, run git submodule update --init --recursive. Use the original dependency notes to restore runtime programs and model files locally.

[AnimationLab Portable](https://github.com/gad4523-maker/animationlab-portable) is the smaller repo for Gemini Tasks.
