=== rigby.js --help (exit=0) ===
Rigby2D command-line tool 0.6.0

Usage: rigby <command> [arguments] [--json]

Commands:
  inspect     Summarize a project: counts, animations, skins, constraints, film settings
  rig         Show the bone hierarchy (setup pose), the slots in draw order and the skins
  animation   Show one animation: duration and the key times of every timeline
  pose        Evaluate the skeleton (setup pose, or an animation at a time): world bones, attachments, bounds
  validate    Check a project for problems (exit code 1 when it is invalid)
  convert     Convert between .rigby, skeleton JSON (3.8 / 4.2 / 4.3) and binary .skel
  export      Export for games: skeleton + packed atlas, a Defold model, or sprite sheets
  import-psd  Turn a layered PSD into a .rigby work file (one slot per layer, laid out as drawn)
  autorig     Rig layered artwork in one step (a PSD, or an unrigged .rigby): bones, meshes, weights, IK
  run         Run a Python script with the rigby scripting API against a project, then save it
  render      Render animations to MP4, WebM, a PNG sequence or GIF on the GPU
  tools       List the operations `rigby call` can run (the MCP server tools)
  call        Run any MCP tool: add_bone, set_bone_key, batch_edit, retarget_animation, lip_sync, ...

Options for every command:
  --json        Print the result as JSON (errors too: {"error": ...}).
  -q, --quiet   No progress messages.
  -h, --help    Help for a command: rigby <command> --help

Exit codes: 0 done, 1 failed (or validate found problems), 2 wrong usage.
Docs: https://rigby2d.com/docs/cli.html
